スプレッドシート連携設定

URLを入力すると、読み取り結果がスプレッドシートへ自動送信されます。

GASスクリプトの作成・設定手順

  1. Googleスプレッドシートを新規作成します。
  2. メニューの [拡張機能] > [Apps Script] を開きます。
  3. コードエディタに以下を貼り付けて保存します：
function doPost(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    var data = JSON.parse(e.postData.contents);
    sheet.appendRow([
      data.timestamp || new Date().toLocaleString("ja-JP"),
      data.userId || "",
      data.type || ""
    ]);
    return ContentService.createTextOutput(JSON.stringify({ result: "success" }))
      .setMimeType(ContentService.MimeType.JSON);
  } catch(err) {
    return ContentService.createTextOutput(JSON.stringify({ result: "error", error: err.message }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
  1. [デプロイ] > [新しいデプロイ] をクリック。
  2. 種類で 「ウェブアプリ」 を選択。
  3. アクセスできるユーザーを 「全員 (Anyone)」 に指定してデプロイ。
  4. 発行された ウェブアプリURL を上記入力欄に貼り付けます。

Webサイトとしての公開手順

このファイル1つ（index.html）をGitHub PagesやNetlify等の無料ホスティングにアップロードすると、スマホのSafariやChromeからアクセス可能になります。

GitHub Pages (無料・HTTPS対応)

  1. GitHubでリポジトリを作成。
  2. このコードを index.html でコミット。
  3. Settings > Pages の Source を main に設定して保存。
